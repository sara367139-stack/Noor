# ✨ Features

- 🔐 Firebase Authentication
- 👤 User Profile
- 📸 Profile Picture Upload
- 🌙 Dark Mode
- 🌍 Arabic & English Localization
- 🕌 Prayer Times API
- ⏳ Next Prayer Countdown
- 📖 Holy Quran
- 🤲 Morning & Evening Adhkar
- 🧭 Qibla Compass
- 📱 Responsive UI
- 🔥 Firebase Firestore
- ☁ Firebase Storage
